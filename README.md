**Nippon in Numbers** — a national statistics site for Japan. The official numbers of a country of 123.8 million people, in one offline site: headline indicators, population and vital statistics with charts, GDP and consumer prices, work and life expectancy, a searchable and sortable table of all 47 prefectures, an indicator explorer (line/bar charts with computed key facts), and a sourced glossary. Every figure names its official source (Statistics Bureau of Japan, Cabinet Office, MHLW) and reference year. Static files only, no build step, no network requests; works on desktop and phone.

## Run it

```sh
node serve.ts            # serves app/ at http://localhost:8080
# or open app/index.html in a browser, or:
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts   # copies app/ + screenshots/ to out/ and writes out/dossier.json
```
